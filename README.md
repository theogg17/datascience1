# Uruguay Labor Market Data Science Project

This project is a complete, reproducible data science workflow focused on Uruguay's labor market over the last 20 years. The main deliverable is the notebook:

- `uruguay_labor_market_project.ipynb`

## Project Goals

- Collect public data from the World Bank API.
- Explore labor market trends visually.
- Build a regression model to interpret relationships between indicators.
- Build a time-series model to forecast unemployment.

## How to Run

1. Create a Python environment with the libraries used in the notebook:
   - `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`, `statsmodels`
2. Open the notebook in Jupyter:

```bash
jupyter lab
```

3. Run the notebook from top to bottom.

## Data Sources

- World Bank API: https://api.worldbank.org/

The notebook includes a "Problem Framing" section with the initial questions, and all analysis steps are documented in English.
